Browser autenticado/MFA, viewport mobile 390×844 e destinos autorizados da sessão.

| Destino | Resultado |
|---|---|
| Início | Página DashboardV2 oficial, sem banner de preview |
| Pedidos | Aba renderizada |
| Rotas | Aba renderizada |
| Motoboys | Aba renderizada |
| Relatórios | Aba renderizada; analytics de área não atendido pelo fixture |
| Eventos | Aba renderizada |
| Ajustes | Aba renderizada |
| Ajuda | Aba renderizada |
| Administração | Aba aparece conforme capability do principal |
| Laboratório/integrações | Aba aparece conforme capability do principal |

No celular, Mais exibe Gestão, Administração e Suporte; ícone é SVG local de três linhas, com rótulo, botão de fechar, alça, rolagem e safe area. Fechamento por botão, Escape e clique fora; Escape/clique externo restauram foco ao acionador e o overlay deixa de interceptar a interação. Sidebar tablet/desktop expõe destinos permitidos, sem inventar rotas. Detalhe no [Browser report](browser-report.json), screenshot [More 390×844 escuro](capturas/more-390x844-dark.png).

Rotas são navegáveis e foram abertas, mas uma auditoria funcional completa de cada formulário/página excede o escopo de promover a Home; páginas ainda legadas permanecem registradas como pendência.
