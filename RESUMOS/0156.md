# Resumo — Campanha 0156

**Resultado: PARTIAL.** A API teve uma redução observada de p95 de 497,31 para 352,45 ms no benchmark comparável com 10 sessões independentes, dois tenants e pool 5; as consultas por resposta caíram de 11 para 9. A fase posterior subiu para 567,68 ms, então uma rodada curta no Termux não prova estabilidade nem capacidade sustentada.

O caso de plano foi reproduzido com 250 pedidos por tenant: estimativa 1/250 antes de `ANALYZE`, 209/250 depois, mesmo índice e execução próxima de 1,3 ms. A causa foi estatística de fixture desatualizada; sem migration ou índice novo.

O mapa Motoboy não carregava o script Leaflet global que `refreshHomeMap()` exige. Após incluí-lo e versionar o cache PWA, Chromium/CDP mostrou tiles cartográficos locais, com atribuição de fixture explícita, e marcador em desktop e mobile, sem overflow ou erro. Tiles públicos e GPS físico não foram testados.

`npm test` Restaurante/Motoboy, PostgreSQL identidade/HTTP/sync/isolamento e Browser E2E passaram. Só `rotamoto_e2e` foi utilizado; o oficial `rotamoto` não foi acessado. Fixtures sintéticas permaneceram retidas com manifestos, inclusive uma execução falha sem commit; nenhuma limpeza foi feita.
