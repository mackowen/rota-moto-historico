# Resumo 0308 — Limpeza concluída para bootstrap inicial

As bases `rotamoto` e `rotamoto_e2e` foram limpas usando o reset administrativo versionado. Os dois ensaios com `commit_reset=false` passaram em rollback; depois o reset foi commitado e validado em cada banco. Estrutura, schema, índices, constraints, funções, ACL/RLS, 71 migrations e 10 permissões foram preservados. Empresas/usuários e todas as demais linhas operacionais foram removidos. Os latches singleton foram reabertos.

As APIs foram paradas durante o reset e reiniciadas depois. `/api/identity/bootstrap/status` está `ready` nos dois ambientes e health/readiness HTTP 200 nas quatro frentes 8081–8084. No oficial, bootstrap local-only está disponível; SMTP/entrega de convite não está configurado. Nenhum owner/empresa foi criado, pois o primeiro bootstrap requer os dados do proprietário em terminal interativo.
