# Resumo 0306 — Rotas Nginx e APIs fora do ar

As rotas são: oficial Restaurante/Motoboy `8081/8082 → 8788`; E2E Restaurante/Motoboy `8083/8084 → 8787`. O Nginx instalado do Restaurante E2E estava divergente e encaminhava para `8788`, upstream oficial. Corrigi as quatro referências para `8787`, preservei backup e `nginx -t`/reload passaram.

As APIs permanecem DOWN por dependências privadas ausentes: o oficial exige `~/rotamoto-data/official-api/runtime.env`, ausente; o E2E tenta inicializar o keystore sob `~/rotamoto-data`, raiz ausente (`ENOENT`). PostgreSQL e `.pgpass` foram confirmados com conexões somente leitura válidas. Não gerei/recriei chaves nem restaurei arquivos privados. Health routes em 8081–8084 retornam 502 enquanto os serviços não iniciam.

O erro de interpretação do Registro 0305 foi esclarecido: os servidores estáticos temporários ocuparam portas de upstream durante os testes de browser, então aqueles 404 não mediam o E2E configurado. Ver [registro 0306](../REGISTROS/0306.md) e [evidências](../EVIDENCIAS/0306/rotas-e-servicos-2026-11-09.md).
