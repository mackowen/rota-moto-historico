## Implementação

- Novo [adapter iFood](/data/data/com.termux/files/home/projetos/repos/rota-moto-restaurante/backend/logistics/providers/ifood.js): fronteira server-side injetável, URL oficial fixa HTTPS, redirect recusado, timeout, limite de resposta, schemas estritos, erros sanitizados (`auth`, `rate_limit`, transitório, permanente e desconhecido), cache de token isolado pelo digest das credenciais e sem log de header/payload.
- Capacidades no adapter: quote, dispatch request, cancel request, tracking, assinatura HMAC e normalização de eventos. Quote exige ID e timestamps válidos, rejeita expiry, mantém BRL explícito, converte decimal documentado em minor units, e não usa preparation time como ETA. Tracking valida latitude/longitude em par e limites geográficos; posição externa não é transformada em localização Motoboy.
- `requestDriver` e cancelamento só retornam `requested / pending` para resposta HTTP 202. Não há retry automático para side effects potencialmente duplicados. Timeout resulta estado desconhecido para reconciliação.
- Credential boundary é `credentialResolver(companyId, 'ifood')`; credencial não vem de frontend, tabela operacional ou `secret_ref` acessível ao runtime. Resolver real/keystore e tela de configuração segura por tenant não foram ligados.
- Nenhum endpoint HTTP externo/webhook foi exposto. HMAC é somente função verificadora sobre bytes brutos; faltam armazenamento idempotente, limite/tenant routing/audit endpoint e proteção persistente de replay.
- A UI de providers agora informa modo `MANUAL`, `API NÃO CONFIGURADA` para iFood sem worker/credencial/homologação, `API BLOQUEADA` para 99Food/Keeta e capability não validada para providers customizados. Dispatch manual continua dizendo que não chama API. Capability persistida continua somente `manual_assignment`.
- Analytics seguem o baseline 0081 (própria/externa, provider, custos conhecidos/cobertura por moeda). Métricas de API — quotes, sucesso/falha, confirmação, retries, cancelamento e divergência — não foram adicionadas, pois não há execução/persistência de API no runtime.
- Fallback manual e para frota própria permanece segundo as restrições de lifecycle existentes. Fulfillment externo não recebe Driver. Não houve mudança no Motoboy.
- Documentação operacional adicionada em [HYBRID-LOGISTICS.md](/data/data/com.termux/files/home/projetos/repos/rota-moto-restaurante/docs/operations/HYBRID-LOGISTICS.md).
