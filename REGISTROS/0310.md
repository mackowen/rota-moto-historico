## Solicitação e causa

O proprietário observou que a página ainda não mostrava o comando corrigido. Embora o `bootstrap-wizard.js` já selecionasse o comando com base no alvo E2E, `bootstrap.html` continuava referenciando a versão antiga `642a2dbd07114e39`; o `asset-manifest.js` também preservava o hash antigo. Um navegador com cache podia continuar executando o JavaScript anterior.

## Correção

Executado o gerador oficial `npm run assets:sync`, que atualizou o URL versionado para `bootstrap-wizard.js?v=14dd2ade9d51b7d2`, o hash do `bootstrap.html` no manifesto e o cacheName do shell. Não foram alteradas regras funcionais nesta correção complementar.
