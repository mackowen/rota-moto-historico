# Campanha 0188 — Concorrência de aceite e atribuição

**Resultado: PARTIAL.** O PostgreSQL E2E comprovou concorrência e serialização segura nas rotinas reais de disponibilidade, despacho automático/FIFO, atribuição, RETURN e receipt. A disputa exigida entre dois motoboys sintéticos distintos aceitando a mesma Delivery por sessões e perfis Browser independentes não foi executada; portanto não se declara esse cenário PASS.

## Teste executado

`NODE_ENV=test ROTAMOTO_E2E_CAMPAIGN=0188 ... npm run test:availability-concurrency-e2e` usou exclusivamente `rotamoto_e2e`. O runner verificou identidade/ledger de migrations 0039–0040, RLS/FORCE nas tabelas de fila, abriu schema derivado isolado com as migrations versionadas até 0044 e o reteve no manifesto. Não executou DROP/TRUNCATE/limpeza.

| Cenário | Resultado | Evidência |
|---|---|---|
| Sessões e locks independentes | PASS | Duas sessões autenticadas e várias transações PostgreSQL independentes observaram lock waits determinísticos; nenhuma espera permaneceu ao final. |
| Aceite/disponibilidade versus atribuição | PASS no modelo exercitado | Comando Offline concorrente com atribuição automática: lock ordenou os efeitos; Offline antes rejeitou assignment sem alterar a Delivery, assignment antes permaneceu canônica. Replay foi idempotente. |
| Dispatch FIFO e reentrega | PASS | Dois comandos de REDELIVERY foram serializados na fila e alocados a dois Drivers elegíveis distintos; uma segunda sessão não recebeu o mesmo Driver. Retry não duplicou eventos/auditoria. Cenário inclui duas Deliveries distintas, não duas tentativas sobre a mesma Delivery. |
| RETURN receipt | PASS | Recebimento com mesma chave produziu operação/fato únicos; chaves distintas concorrentes resultaram em uma confirmação aceita e outra obsoleta/convergente. |
| Lease/fencing e rollback | PASS | Expiração de lease foi rejeitada; chave idempotente concorrente produziu um receipt; proprietário de lease único; rollback removeu seu comando. |
| Tenant isolation | PASS | Driver elegível de tenant B permaneceu invisível à fila de tenant A. |
| Duas identidades de motoboy | BLOCKED/não executado | As sessões de disputa disponíveis no runner apontam ao mesmo Driver sintético; não foram criados dois usuários, memberships e perfis Chromium independentes. |
